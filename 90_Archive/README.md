# 90_Archive

Finished and closed things. Completed projects, retired areas, old notes you do not want to delete.

## Rules

- Move whole project folders here with their COP when the project ends.
- Change the project's status to `completed` in `10_Command Center/Vault Index.md` at the same time.
- Tell the agent, so it updates the Memory Bank. Otherwise it keeps treating the project as live.
- Nothing in here is loaded at `/prime`. The agent only looks here when you ask.

## Why archive instead of delete

The agent can answer "how did we handle X last year?" only if the notes still exist. Archiving keeps the history searchable without cluttering the active context.
